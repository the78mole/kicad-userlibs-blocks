# KiCad-Userlibs: Design Blocks

Eigene KiCad-Design-Blocks. Das Repository enthält derzeit noch keine Blöcke.

## Verwendung

Das Repository wird in KiCad über die Pfadvariable `THE78MOLE_LIBS` eingebunden, z. B. `${THE78MOLE_LIBS}/blocks`.
`THE78MOLE_LIBS` zeigt auf das Verzeichnis, in dem dieses Repository als Unterordner `blocks` liegt.
